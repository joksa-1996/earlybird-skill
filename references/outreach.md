# Handing leads to outreach tools

Earlybird stops at the company and the public post. It has no LinkedIn data and never contacts anyone.

## If the user has an outreach, LinkedIn or CRM connector

Some users connect a tool for LinkedIn data, outreach campaigns or a CRM. If such tools are available in this conversation and the user wants to act on leads:

1. Follow that tool's own instructions or guide where it has one.
2. Look up the chosen leads there (profile, recent activity) only if the user asks.
3. Check whether a lead is already in a campaign or sequence. **A lead is never added to two campaigns at once.** If it already is in one, show which and skip it.
4. Ask which campaign, list or pipeline to use. Do not pick for the user.
5. Add leads only after a clear yes. Pass Earlybird's "why now" as context.
6. Never send a message from Earlybird.

## If no such tool is connected

Help with what the public sources give: a short summary of each lead the user can use manually (what they do, the signal, the link, a first line based on the signal). Do not recommend specific products.
